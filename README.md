# Calculadora de dosificación de químicos

Aplicación web instalable (PWA) para M1 y M2 de Moldeados Venezuela:

- Producción en t/h a partir de bultos/h, separadores por bulto y peso del separador (g).
- Sugerencia del proveedor (L de químico por t) a dosis (ml/min) y al revés.
- Consumo diario y mensual, duración del contenedor y contenedores por mes.
- Cuadro de combinaciones de dosis de M1 y M2.

Los datos que escribe el usuario se guardan solo en su teléfono.

## Instalar en el teléfono

- Android (Chrome): abrir el enlace de GitHub Pages, menú ⋮ y «Instalar aplicación» o «Agregar a pantalla principal».
- iPhone (Safari): abrir el enlace, botón Compartir y «Agregar a inicio».
